## 1. The project in one paragraph
Management application for a friend's ready-mix concrete company in Tétouan (plants Tétouan = BELGO and Chefchaouen = CHAOUN; one office in Tétouan). It replaces Odoo (removed by the owner). It tracks money and materials together: clients, suppliers (cement, sand, other components), transport, fuel, what came in/out/was cancelled, cash vs cheque vs instalments, cheques due, advances, stock. The plant's own software reports what was loaded (e.g. B20) and the app deducts components by recipe. Owner has a private interface (little time, many problems); two office employees enter transactions; plants and drivers use phones. The owner wants APIs, agents and automation of routine work. Ali (builder, OBSIL MEDIA) is the owner's contact and decides everything on the build side.

## 11. Lessons and gotchas
- `pnpm` missing in a new terminal: `corepack pnpm …`. Never `claude --model sonnet.`.
- e2e: one full pass on AC power under `caffeinate -dimsu` (~35–45 min); Mac sleep on battery caused fake timeouts.
- Claude Code resumes after a network loss by itself (10 retries); say "continue" if not. Ignore "Update installed".
- SSH: "Enter passphrase for key" is the LOCAL key passphrase, not the server password (use `ssh-add --apple-use-keychain`). sshd takes the FIRST value it finds across drop-ins in lexical order (`00-kayas.conf` wins over cloud-init's `50-`). Always test a SECOND session before closing the first. Ubuntu 24.04 starts sshd on first connection (socket), so `/run/sshd` may be missing for `sshd -T` (create it).
- **Ali's network is NAT64/DNS64: `ssh` cannot resolve `kayas.aliobsil.com`; always SSH to the IP 149.56.132.58** (browsers and curl resolve the name fine). Use `-o IdentitiesOnly=yes -o ServerAliveInterval=30 -i <key>` to avoid idle drops. A repo key with a passphrase breaks a non-interactive `git clone` ("Bye Bye"): the read-only deploy key has no passphrase.
- Hidden prompts: a typo or the wrong keyboard layout (input source switched) gives a failed password with no visible clue; paste from the password manager. When a pasted block contains `sudo`, run `sudo -v` ALONE first: otherwise the following pasted lines are eaten as the password.
- GitHub Actions: the image digest is printed by the step "Digest to deploy" of the Build-and-push job; the digest under Artifacts is the build record. Copy it from the page.
- `docker login` leaves an empty `{"auths": {}}` after `docker logout`; `grep -c auth` counts the word "auths" (returns 1): check the file is 16 bytes / `"auths": {}` instead.
- A hardened Caddy (cap_drop ALL) cannot read a 0600 file owned by another uid; the macOS Docker Desktop rehearsal masks ownership, so permission bugs only show on a real Linux host. An atomic rewrite of a single bind-mounted file leaves the container on the old inode.
- Caddy's log in this configuration does not print an "obtained certificate" line; verify with curl (no -k) and `openssl s_client`.
- Docker bypasses UFW for published ports; publish only 80/443. `sudo docker` (docker group = root-equivalent).
- bcrypt hashes contain `$`: never put them in Compose env; mount a file.
- Tests that assert a substring of a random sealed value are flaky; assert format instead.
- Rate limiting is a protection; never retry blindly (5 wrong PINs lock a driver).
- Screenshots may expose secrets or links (OVH reset link): warn, do not open, do not repeat. Ali's staging Basic Auth user name looks like a person's name: tell him it is visible in chat/screenshots and can be changed by re-running `make-basic.sh` only after T10i is deployed.
- **External port scans:** a full fast scan over a hotspot/ISP can lose replies and be answered by a middlebox (4 ms to a Canadian host is impossible). Validate a scan with a known-open port; use targeted `-T3 --reason` scans of the ports that matter plus host-side `ss -ltn` / `verify-host`.
- **Two different logins on staging:** the browser's "Sign in" dialog is the Basic Auth (the user/password chosen with make-basic.sh); only after it comes the red KAYAS login page where the fictitious accounts of show-accounts.sh are used. Phone keyboards add capitals/spaces: paste instead of typing. Open each role in a separate private window.
- **Signature checks on macOS:** `codesign -dv --verbose=2` shows `Signature=adhoc` / `TeamIdentifier=not set` for re-signed (cracked) binaries; `codesign --verify --deep --strict` shows patched bundles. These checks show tampering, not what an installer did.
- The lead must not guess: verify in the repo through the bridge; read doc sections from the VPS before giving commands; when a plan changes, update this file.
