## Findings ranked blocker / high / medium / low

No **blocker** or demonstrated default-profile unauthenticated disclosure of business amounts was established by this review. The following **high** findings prevent blanket approval of the seed/admission and custom output paths; the restricted GO requires avoiding those paths explicitly.

### R12-01 — High — admission still does not establish an empty database in all supported configurations

**Verified:** `assertSeedTargetEmpty` checks only `user`, client, supplier, sales_order, purchase, truck, driver, invoice and payment_instrument. It does not check existing finance rows, money accounts, plants, or other application tables. Finance entries permit NULL optional parent references and have no user foreign key on `created_by`; their amounts/references are later read by finance. Evidence: [`scripts/seed-training.ts:104`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/scripts/seed-training.ts#L104), [`db/migrations/0200_finance_core.sql:125`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/db/migrations/0200_finance_core.sql#L125), [`src/modules/finance/service/reference-service.ts:34`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/src/modules/finance/service/reference-service.ts#L34).

**Inference:** an unmarked, partially restored/sanitized database containing finance-only records can pass the nine probes, receive training users and a marker, and expose surviving amounts through the training finance roles after their real TOTP enrolment. This requires operator-selected database contents, not a remote way to replace the database. A pristine volume avoids this scenario.

**New bypass introduced by the fix:** `TRAINING_ALLOW_UNMARKED=true` is described as “e2e only”, but validation permits it with the ordinary deployed combination `APP_ENV=training`, `TRAINING_MODE=true`, `REAL_DATA=false`. There is no runtime test-environment requirement. The Compose app imports an environment file and does not override this flag to false. Sources: [`src/lib/training.ts:29`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/src/lib/training.ts#L29), [`src/lib/env.ts:193`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/src/lib/env.ts#L193), [`docker-compose.training.yml:35`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/docker-compose.training.yml#L35). A source test asserting the flag is absent from Compose/init text is not a runtime prohibition.

**Correction:** check all non-reference business state across public/finance (with an explicit migration-created reference-data allowlist), and prevent the test escape in the deployed training service. **Training containment:** initialize a demonstrably new dedicated training database volume; never restore/reuse another dataset; independently confirm the escape is absent/false in the running app. A banner and `REAL_DATA=false` alone are insufficient.

**Inference:** a failed/interrupted local or custom-path seed can leave every issued password/PIN in a file eligible for an ordinary `git add` or a local Docker build's `COPY . .`. Mode 0600 protects against other OS users, not the operator's Git/build process. The runtime image copies the build workspace: [`Dockerfile:9`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/Dockerfile#L9), [`Dockerfile:23`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/Dockerfile#L23). That volume is private and not a host checkout/build context, so this specific leak is not on the approved deployment path. Keep the marker last; a failed seed must remain unserved.

**Verified:** the route counts failures, then parses/verifies the request, then inserts a failure. It skips every `LOCKED` outcome, including the fifth wrong PIN that actually caused a driver lock: [`src/modules/field/service/auth.ts:269`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/src/modules/field/service/auth.ts#L269). Unknown/malformed IP returns “not locked”: [`src/modules/platform-security/auth/login-guard.ts:30`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/src/modules/platform-security/auth/login-guard.ts#L30).

**Inference:** concurrent requests can all pass the IP probe before their failures are recorded; unknown codes still invoke Argon2 without the known driver's row serialization. The limit therefore reduces sequential abuse but does not bound a concurrent burst to the configured 20 failures. This does **not** reopen the fixed five-guesses-per-driver chain. Lockouts still allow deliberate availability disruption, which supervision must handle.

The new IP test inserts failures serially and calls the helper directly; it does not exercise concurrent HTTP admission or the real proxy: [`tests/field-ip-throttle.int.test.ts:16`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/tests/field-ip-throttle.int.test.ts#L16).

**Correction:** reserve attempts atomically per trusted IP before expensive work, account for every verified wrong PIN, and bound concurrent/in-flight work. **Training condition:** accept the remaining availability risk only for supervised sessions, retain fresh six-digit seed PINs and device binding, and prove on the actual Funnel that forged incoming forwarding headers cannot change/disable the selected client IP. If that check fails, this GO does not cover public phone training.

**Inference:** a connection that stalls rather than promptly failing leaves client details on screen beyond expiry; browser network timeouts decide how long. Concurrent timer/resume requests are also not versioned, so stale responses need care when implementing expiry/logout. No race exploit was reproduced. Current tests cover promptly offline failure and revocation responses, not a refresh held pending across expiry: [`e2e/driver-app.spec.ts:343`](https://github.com/aliescoobs-sudo/beton/blob/b672a6b589be6931af9803d0cb34bf380cd8ac60/e2e/driver-app.spec.ts#L343).

**Correction:** immediately hide/erase an expired day independently of network completion, use a bounded refresh, and reject obsolete responses after logout/account changes.
