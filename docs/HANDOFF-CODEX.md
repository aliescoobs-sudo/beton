## 5. المعمارية [متحقق جزئيا فالملفات، والتفاصيل فـ CAPABILITY-MAP.md و`module-map.mjs`]

- **التقنيات:**
  - Next.js 16 (Turbopack) وTypeScript؛
  - PostgreSQL 17 فـ Docker (Colima)؛
  - migrations بـ SQL أولا (`db/`)؛
  - RLS مع FORCE، وcolumn grants، ودوال SECURITY DEFINER فيها فحص الدور واختبارات كشف (exposure)، وviews بـ security_barrier؛
  - سجل تدقيق مسلسل بالـ hash (hash-chained audit)؛
  - Better Auth مع TOTP وstep-up؛
  - pg-boss، Vitest، Playwright؛
  - next-intl fr/ar مع RTL؛
  - الـ dev server مربوط بـ 127.0.0.1، والدخول غير عبر `http://localhost:3000`.
- **الوحدات (`src/modules/*`):** ledger، operations، master-data، rules-engine، assistant… وكل وحدة عندها public index. القواعد ديال الاستيراد بين الوحدات فـ `module-map.mjs`.
- **مسار المعطيات:** الشاشة ← service ← الـ DB تحت الـ RLS ديال الجلسة. المبالغ كيحسبها الكود أو الـ DB بالسنتيمات. المكتب كيمر من «أبواب» (office doors، migration 0052) كترجع غير الرقم، بلا ثمن ولا مجموع.
- **المساعد:**
  - `src/modules/assistant` و`src/app/api/assistant`؛
  - provider interface مع `FakeProvider` افتراضيا؛
  - adapter ديال Anthropic مقفول بأربعة شروط؛
  - الأدوات كتخدم بجلسة المستخدم نفسو؛
  - pseudonymization وleak scan وpost-check ديال الأرقام؛
  - المسودات (`ai_proposal`) كتتأكد من طرف إنسان، بـ step-up ملي يكون فيها الفلوس.
- **التكاملات الخارجية:** حتى وحدة مفعلة. AI مطفي بالـ flags (`ASSISTANT_ENABLED` و`AI_EXTRACTION_ENABLED`)، ومرفوض مع `REAL_DATA=true` أو فالـ production.

  - ما كيكتبش بلا بطاقة كيأكدها إنسان؛
  - ما كيشوفش أكثر من المستخدم؛
  - الـ flag مطفي فالحقيقي حتى يجي تصريح CNDP.
- **Git والتشغيل:**
  - مهمة وحدة فكل commit مع الفحوص الكاملة؛
  - Decision 79؛
  - `db:scenario` idempotent؛
  - الـ e2e بـ worker واحد؛
  - ما تزيدش الـ timeouts باش تخبي الأعطال؛
  - ما يتحفظ حتى سر فـ Git؛
  - النموذج الحقيقي ديال AI ما يتشغلش؛
  - السجلات ديال الاختبارات فـ `./.logs/` (gitignored).

## 14. محاولات سابقة مرفوضة أو متوقفة

- **Odoo:** المالك خدم بيه وحيدو. بغا حاجة أبسط، فيها API وأتمتة.
