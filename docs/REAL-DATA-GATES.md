## How to close a gate

1. Run the rehearsal or collect the evidence named in the last column, on the approved release or a disposable synthetic copy.
2. Put the evidence (or its location) in the "What was added" column of this file in the same commit, with the date and the commit it applies to.
3. Change the state of the gate to **CLOSED (evidence)** only in that commit, and only if the reviewer's closing condition in `CODEX-REVIEW-R18.md` is met. Otherwise say what is left.
