# بطاقة تمارين — المسؤول

معطيات **وهمية**. الحساب المستعمل: « Administrateur » (admin@formation.kayas.invalid). لا ترد كلمات المرور في أي بطاقة: تُسلَّم يدا بيد.

## ما يجب تجربته
1. **الحسابات**: *الإدارة ← إدارة المستخدمين*: قائمة حسابات التدريب بلا كلمات مرور.
2. **الإعدادات والسجل**: *الإدارة ← الإعدادات* و*الإدارة ← السجل* (سجل الأحداث: ترى فيه كل الإجراءات، وغيرك لا يرى إلا إجراءاته): تتبّع ما قام به المتدربون الآخرون (من، ماذا، متى).
