# Fiche d'exercices — Bureau achats

Données **fictives**. Compte à utiliser : « Bureau achats » (achats@formation.beton.invalid). Les mots de passe ne figurent dans aucune fiche : ils sont remis en main propre.

## À essayer
1. **Livraison à recevoir** : ouvre *Achats* ; l'achat de ciment (30 t) de Tétouan est en attente. Confirme la réception avec les détails du fournisseur une fois que le chef de centrale a compté l'arrivage. Résultat : le stock de ciment augmente.
2. **Commander pour stock bas** : la centrale de Tétouan a une alerte de ciment bas (*Stock*). Crée un achat de ciment pour Tétouan. Résultat : un code ACH-… ; l'alerte reste tant que la livraison n'est pas reçue.
3. **Contrôle** : ouvre *Factures fournisseur* : tu vois les factures en attente de rapprochement avec les réceptions, sans pouvoir approuver (c'est le propriétaire).
