# Fiche d'exercices — Chauffeur (CH-01, CH-02, CH-03)

Données **fictives**. Compte à utiliser : le code chauffeur remis en main propre (CH-01, CH-02 ou CH-03) et son PIN, sur le téléphone, adresse /fr/driver. Les mots de passe ne figurent dans aucune fiche : ils sont remis en main propre.

## À essayer
1. **Liste du jour** : tu vois tes livraisons dans l'ordre (client, chantier, volume). Aucun prix.
2. **Faire une rotation** : appuie sur le bouton de l'étape proposée : début de chargement, départ (après le bon de livraison de la centrale), arrivée, début de déchargement, fin de déchargement, retour. Résultat : l'étape se cale sur l'heure du téléphone et la rotation suivante devient l'étape en cours.
3. **Coupure réseau** : passe en mode avion, appuie sur une étape, remets le réseau. Résultat : l'étape est envoyée avec l'heure où tu as appuyé.
4. **Urgence** : bouton d'urgence (panne, accident…) : le chef de centrale reçoit une alerte et peut te donner une instruction.
5. **Fin de journée** : *Se déconnecter* efface la journée du téléphone.
