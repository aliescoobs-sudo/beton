# Fiche d'exercices — Bureau ventes

Données **fictives**. Compte à utiliser : « Bureau ventes » (e-mail ventes@formation.beton.invalid ; mot de passe : voir la fiche remise en main propre). Les mots de passe ne figurent dans aucune fiche : ils sont remis en main propre.

## À essayer
1. **Devis à transformer en commande** : ouvre *Devis*, choisis un des deux devis ouverts, transforme-le en commande. Résultat : un code CMD-… apparaît dans *Commandes* ; tu ne vois aucun montant (profil bureau).
2. **Vente comptant, client à crédit, chèque en trois échéances** : dans *Commandes*, regarde les quatre commandes du jour (comptant, chèque à 30 jours, trois échéances, avance 50 %). Ouvre-en une : le plan de paiement est affiché, sans prix.
3. **Nouvelle commande** : *Commandes → Nouvelle*, client Démo 3, B25, 12 m³, livraison demain. Résultat : un code CMD-… ; la commande attend le plan de la centrale.
4. **Annulation** : la commande de demain (client Démo 2, B20, 8 m³) n'est pas encore produite : annule-la avec un motif. Résultat : elle sort du plan et une écriture d'annulation est créée (rien n'est supprimé).
